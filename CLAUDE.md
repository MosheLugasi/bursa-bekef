# CLAUDE.md – בורסה בכיף (Bursa Be'Kef)

**Shori (שורי)** – Hebrew (RTL) educational paper-trading game for kids 7+ and beginner adults. Static SPA (Vite + React 19 + TS + Tailwind v4 + Zustand) deployed to GitHub Pages; real market data is fetched daily by GitHub Actions. The owner manages the project from Claude on mobile – keep changes small, tested, and pushed.

## Commands
- `npm run dev` – dev server (needs `public/data/`, see below)
- `npm test` – vitest engine tests (`src/**/*.test.ts`) – must pass
- `npm run build` – `tsc -b && vite build` – must pass (strict TS, no unused locals)
- `npm run devdata` – **synthetic** dev data via `pipeline/make_dev_data.py` (Yahoo Finance is blocked in Claude cloud sessions; never commit or deploy this data – `public/data/` is gitignored and the manifest is flagged `synthetic: true`, which shows a warning banner)
- Real data: `python pipeline/fetch_data.py --out public/data --cache data-cache` (runs in `.github/workflows/deploy.yml`)

## Architecture
- Pages (Vite multi-page, see `vite.config.ts`): `/` Hebrew landing + `/en/` English landing are **static HTML** rendered by `landing/plugin.mjs` from `landing/content.mjs` (copy, `FACTS` – kept in sync with the code by `src/landing.test.ts`) + `landing/render.mjs` (SEO meta, hreflang, OG, JSON-LD, sitemap/robots) + `landing/landing.css|js`; root `index.html` / `en/index.html` are just placeholders. The game itself is `app/index.html` → `/app/` (HashRouter). Landing CTAs link to `app/?start=google|guest` (`src/state/startParams.ts`); returning players are redirected from the landing to `/app/`. Canonical/OG URLs use `SITE_URL` (default `https://shori.co.il/`). The build uses a **relative base (`./`)** so the same output works at the domain root and under `github.io/bursa-bekef/`; runtime paths come from `src/ui/links.ts` (`SITE_ROOT` = parent of `/app/`), the PWA manifest is `public/manifest.webmanifest` and the service worker is registered manually in `main.tsx` (don't use `import.meta.env.BASE_URL` for URLs). Screenshots in `landing/assets/shots/*.webp` (+`sizes.json`) are real app captures with real data; OG images in `public/og/`.
- Brand: name Shori/שורי, mark in `public/brand/shori-mark.svg` and `src/ui/Logo.tsx` (bull whose right horn is a rising arrow). Palette: violet `brand-*` (#5b3df5), gold #f5b83d, ink #0d1022, ivory #faf8f3.
- `src/engine/` – pure game engine. Prices are **raw (not split-adjusted)**; splits/dividends are applied as events in `process.ts#advance`. `market.ts` (MarketData over `closes.json` + per-instrument OHLC), `trading.ts` (buy/sell/limit/SL/TP/options/bonds/valuation), `finance.ts` (Black-Scholes, bond pricing from real yield curves, `BOND_PRODUCTS`), `metrics.ts`. Add tests in `engine.test.ts` for engine changes.
- Game time: every portfolio has `currentDate`. `mode: 'history'` (time machine) advances manually; `mode: 'live'` is auto-advanced to `manifest.asOf` on load (`game/actions.ts#processLivePortfolios`). UI must never show data after the portfolio's `currentDate` (no future leakage).
- `src/content/` – all Hebrew educational content. `universe.json` is the single list of instruments (also read by the Python pipeline). Text supports `[[termId]]` / `[[termId|label]]` glossary links (must be valid ids in `glossary.ts`) and `**bold**`. Company profiles support dated markers (`content/dated.ts`): `{{YYYY-MM-DD|text}}` shows only from that date, `{{<YYYY-MM-DD|text}}` only before it – the time machine uses them to hide future events, so wrap any new time-sensitive fact. Types in `content/types.ts`.
- `src/game/` – XP/levels, achievements (`achievements.ts`), time-machine challenges, coach tutorials (`coach.ts`, replayable via the header "שורי מסביר" button), feature gating (`features.ts`: kids unlock features by completing lessons), kids' journey (`journey.ts` stations/chapters/stickers/treasure chests + animated scenes in `ui/journey/Scenes.tsx` and `ScenesPercent.tsx`, shared helpers in `ui/journey/kit.tsx`), practice arena (`practice.ts` – pure generators for percent/return drills, daily XP cap; page `pages/Practice.tsx`, tests in `practice.test.ts`).
- `src/state/` – Zustand store persisted to localStorage (`store.ts`), UI store, optional cloud accounts on **Base44** (backend only; `cloud.ts`, SDK `@base44/sdk`): Google login via Base44-managed OAuth (token returns as `?access_token=`), family = account (entity `Family` with `members`/`owners` emails, `max_profiles`), `AccessRequest`, game docs in `FamilyDoc` (`doc_id`, `payload`, `members` copy for RLS). Schemas + RLS in `base44/entities/*.jsonc`, auth in `base44/auth/config.jsonc`; push with the Base44 CLI (`npx base44 login`, `npx base44 deploy -y`; in cloud sessions run node with `NODE_USE_ENV_PROXY=1`). Open signup (`OPEN_SIGNUP` in `cloud.ts`): first Google login auto-creates a family (default `DEFAULT_MAX_PROFILES`); app admins (`role: admin`) can still pause/delete families and set quotas. The repo is 2-way synced with the Base44 app (its builder bot commits to `main` – pull before working); entity changes pushed to `main` sync to Base44 (then Publish in Base44). LWW per doc by `updatedAt`, pulled by server `updated_date`. UI in `ui/Account.tsx` / `ui/AccountAdmin.tsx`.
- Zustand v5: selectors must return stable references (never `useGame(s => Object.values(...))` – select the map and `useMemo`).
- Charts: lightweight-charts v5 (`addSeries(AreaSeries…)`, `createSeriesMarkers`), custom SVG for donut/bars/payoff. Palette in `index.css` / `ui/charts.tsx`; gains/losses always paired with ▲▼ and sign, not color alone.

## Conventions
- All UI text in Hebrew, gender-neutral plural ("אתם"), Hebrew punctuation ״ ׳. Numbers/prices wrapped with `.num` (LTR isolate).
- Mobile-first: test at 390px width; bottom nav on mobile, side nav ≥ md.
- Educational, never investment advice. Don't invent financial figures in content.
- Adding an instrument: add to `src/content/universe.json` (Yahoo symbol; TASE `.TA` prices are in agorot and converted automatically) + a profile in one of `companies-*.ts` (merged in `content/index.ts`). Stocks carry `rank` (market-cap rank within its market, ranked Nov 2026 via `pipeline/research` on the `diag/rank` branch) and `core: true` for kid-familiar brands (always get daily news; others rotate).
- Data size: `closes.json` v2 delta-encodes each series (`{k, d}`); keep the universe around ~220 instruments unless lazy loading is added.

## Deployment
Push to `main` → workflow fetches data (cache on orphan branch `data`), runs tests, builds (relative base, `SITE_URL`), deploys to GitHub Pages – custom domain **shori.co.il** (set in repo Settings → Pages; DNS: apex A records to GitHub Pages IPs, `www` CNAME to `moshelugasi.github.io`). DNS/Pages status can be checked by pushing a `domaincheck/**` branch (workflow `domain-check.yml` lives on that branch). Daily cron 22:40 UTC Mon–Fri. Optional: secret `ANTHROPIC_API_KEY` (Hebrew news summaries via Claude), variable `BASE44_APP_ID` (override the Base44 app; default is in `cloud.ts`).
