# 🐂📈 בורסה בכיף

משחק מסחר בבורסה לילדים (מגיל 7) ולמבוגרים מתחילים – בעברית, עם **נתוני מסחר אמיתיים** מהבורסה בתל אביב ומוול סטריט.
לומדים לבחור מניות, אג״ח ואופציות, לקרוא דוחות וחדשות, לבנות תיק, להתחרות במשפחה – ולאסוף הישגים בדרך.

> ⚠️ זה משחק לימודי עם כסף וירטואלי ("מסחר על הנייר"). שום דבר כאן אינו ייעוץ השקעות. הנתונים מתעדכנים פעם ביום (לא בזמן אמת).

## איך מתחילים לשחק

1. נכנסים לאתר (אחרי ההפעלה: `https://moshelugasi.github.io/bursa-bekef/`).
2. בפעם הראשונה: שם משפחה + קוד הורים, ומוסיפים שחקנים (לכל אחד גיל – זה קובע את רמת ההסברים).
3. כל שחקן פותח תיק: "שוק חי" או "מכונת הזמן".
4. בטלפון: "הוספה למסך הבית" – והמשחק נפתח כמו אפליקציה.

## 🌐 הפעלת האתר בענן (GitHub Pages) – פעם אחת

1. בריפו: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
2. **Actions → "עדכון נתוני שוק ופרסום האתר" → Run workflow** (או פשוט push ל-main).
3. אחרי כמה דקות האתר זמין. מכאן הוא מתעדכן לבד כל יום חול בלילה עם נתוני המסחר של אותו יום.

> GitHub Pages חינמי לריפו ציבורי. לריפו פרטי צריך מנוי GitHub Pro.

## 🌐 דף הנחיתה ומיתוג (״שורי״)

- `/` – דף נחיתה בעברית, `/en/` – באנגלית, `/app/` – המשחק עצמו.
- דפי הנחיתה הם HTML סטטי (טוב לגוגל ולשיתוף ברשתות) שנוצר בזמן ה-build מ-`landing/content.mjs`.
  לשינוי טקסטים – עורכים את הקובץ הזה (עברית ואנגלית באותו מבנה).
- כתובת האתר הקנונית (לגוגל ולתמונות השיתוף) נקבעת במשתנה `SITE_URL` (ברירת מחדל: GitHub Pages).
- הרשמה: ״מתחילים בחינם עם Google״ פותח משפחה מיד (חינם, עד 6 שחקנים), או ״לנסות בלי הרשמה״ (נשמר במכשיר).

## ☁️ חשבונות משפחה עם Google (Base44)

בלי התחברות, המשחק נשמר בדפדפן של המכשיר. עם התחברות: כל משפחה נכנסת עם Google, משחקת מכל מכשיר,
ומנהל המשחק מאשר משפחות וקובע לכל משפחה כמה שחקנים מותר לפתוח. משפחה יכולה לצרף גם חשבון Google של הורה נוסף.

**איך זה עובד:**
- ה-backend (התחברות, משפחות, הרשאות ונתוני משחק) נמצא ב-[Base44](https://app.base44.com) – האתר עצמו נשאר ב-GitHub Pages.
- מי שמתחבר עם Google ועוד לא שייך למשפחה שולח **בקשת גישה**. המנהל רואה את הבקשות במשחק:
  **אזור ניהול → ניהול חשבונות** – מאשר, ובוחר כמה שחקנים מותר למשפחה (אפשר גם להשבית/למחוק משפחה).
- בעלי משפחה יכולים לצרף חשבון Google של בן/בת הזוג (אזור ניהול → חשבון המשפחה).
- ההרשאות נאכפות בשרת של Base44 (Row Level Security) – כל משפחה רואה רק את המידע שלה.
- המנהל = מי שתפקידו `admin` באפליקציה ב-Base44 (בעל האפליקציה מקבל אותו אוטומטית; אפשר לשנות ב-Base44 → Users).

**הגדרות ה-backend בקוד:** התיקייה `base44/` (טבלאות והרשאות ב-`base44/entities`, התחברות ב-`base44/auth`).
עדכון אחרי שינוי: `npx base44 login` ואז `npx base44 deploy -y` מתוך תיקיית הפרויקט.

## 📰 חדשות

כל יום נאספות כותרות אחרונות מ-Google News – **בעברית** לכל חברה (גלובס, כלכליסט, ביזפורטל ועוד), ובאנגלית גם לחברות האמריקאיות.

**תוספת לא חובה – הסבר לילדים לכל כותרת:** אם מוסיפים מפתח של Claude, כל כותרת מקבלת תקציר פשוט, הסבר לילד בן 8 וסימון "חיובי/שלילי":
**Settings → Secrets and variables → Actions → Secrets → `ANTHROPIC_API_KEY`**.

## 📱 ניהול ופיתוח מהטלפון עם Claude

הקוד כולו בריפו הזה, כך שאפשר להמשיך לפתח מכל מקום:
1. ב-[claude.ai/code](https://claude.ai/code) (או באפליקציית Claude בטלפון → Code) בוחרים את הריפו `bursa-bekef`.
2. מבקשים בעברית, למשל: "תוסיף את מניית אלביט הדמיה לרשימה", "תוסיף שיעור על קריפטו", "תשנה את העמלה ל-0.05%".
3. Claude עושה את השינוי, מריץ בדיקות ודוחף – והאתר מתעדכן אוטומטית.

הקובץ `CLAUDE.md` מסביר ל-Claude את מבנה הפרויקט.

## 🛠️ פיתוח מקומי

```bash
npm ci
pip install -r pipeline/requirements.txt
python pipeline/fetch_data.py --out public/data   # נתונים אמיתיים (דורש גישה ל-Yahoo Finance)
# או: npm run devdata  → נתוני פיתוח סינתטיים (כשאין גישה לאינטרנט)
npm run dev
npm test
```

### מבנה הפרויקט

```
src/
  engine/        מנוע המשחק (טהור, עם בדיקות): מסחר, פקודות, אג״ח, אופציות, קידום זמן, סטטיסטיקות
  content/       תוכן בעברית: חברות, מילון, שיעורים, בוחן יומי, אירועים היסטוריים, רשימת הנכסים
  game/          XP, רמות, הישגים, אתגרים, הדרכות שורי, פתיחת יכולות
  state/         מצב המשחק (localStorage) + חשבונות וסנכרון ענן (Base44)
  pages/, ui/    המסכים והרכיבים (React + Tailwind, RTL, מותאם לנייד)
pipeline/
  fetch_data.py  איסוף נתונים אמיתיים (Yahoo Finance + FRED) → public/data
  make_dev_data.py  נתוני פיתוח סינתטיים (לבדיקות בלבד)
.github/workflows/deploy.yml  עדכון יומי + בדיקות + פרסום ל-GitHub Pages
```

### מקורות נתונים
- מחירים, דיבידנדים, פיצולים ודוחות כספיים: Yahoo Finance (דרך `yfinance`).
- כותרות חדשות: Google News RSS.
- תשואות אג״ח ממשלת ישראל וגיבוי לתשואות ארה״ב: FRED (הבנק הפדרלי של סנט לואיס).
- מרווחי האשראי של אג״ח החברות והדירוגים במשחק הם הערכות קבועות לצורכי לימוד.
- הנתונים נשמרים בענף `data` בריפו (גיבוי למקרה ש-Yahoo לא זמין ביום מסוים).
- אם מקור נתונים מפסיק לעבוד: Actions → **"בדיקת מקורות נתונים"** → Run workflow (בודק סימולים, חדשות וסדרות FRED ישירות מהשרתים של GitHub).
